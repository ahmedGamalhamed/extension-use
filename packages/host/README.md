# @extension-use/host

Runs inside your extension: `defineHost()` (router, grants, site policy), the content runtime with page actions, the side panel frame bridge, manifest helpers, the `extension-use` CLI and no-build bundles.

Part of **Extension-use**, which lets a web app drive a browser extension through a fixed, typed set of actions. See the main README and docs in the Extension-use repository.
