# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about the work. Harassment, personal attacks and discrimination aren't tolerated in issues, pull requests, discussions or any other project space.

To report a problem, contact the maintainer privately through the details on [their GitHub profile](https://github.com/ahmedGamalhamed). Reports are kept confidential.
