# Pick your packages

Tell us how your extension is built and what should control it. You get the packages to install and the code for each file, ready to copy.

You don't need all of Extension-use. Most extensions need two packages: `@extension-use/host` in the extension, and `@extension-use/client` wherever the controller runs.
